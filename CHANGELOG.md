# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- **Installer wizard** (`installer/ghostpad.iss`, Inno Setup 6):
  - Per-user install with no admin rights, or an optional all-users install.
  - Start-menu shortcut, plus optional desktop shortcut and start at sign-in.
  - Clean upgrades and an uninstaller that offers to keep or delete notes.
  - Silent-install switches for IT.
- **One-command build** (`tools/build.ps1`): tests, exe, portable zip and
  installer.
- **Exe version details** shown in Explorer and Installed apps.
- **Build and distribution guide** (`docs/BUILDING.md`).

### Changed

- **UPX compression disabled** in the PyInstaller build, to reduce antivirus
  false positives.

## [1.0.0] - 2026-11-13

First release as **Ghostpad**. It was previously the unnamed "Notes" and
"Notes v2" scripts.

### Added

- **Capture shield.** Every app window is excluded from screen sharing,
  recording and screenshots, including popup menus, message boxes and file
  dialogs. A live indicator in the status bar re-verifies protection four
  times a second.
- **Black-box fallback** on Windows versions older than 10 version 2004.
- **Session restore.** Untitled notes autosave. Window position, size, zoom,
  opacity, word wrap, always-on-top and the last opened file are restored on
  launch.
- **Find bar** (<kbd>Ctrl</kbd>+<kbd>F</kbd>, <kbd>F3</kbd>,
  <kbd>Shift</kbd>+<kbd>F3</kbd>) with highlighting and a match count.
- **Global presenter hotkeys** <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd>
  to scroll notes while another app has focus.
- **Single-instance launch.** Starting Ghostpad again brings the running window
  to the front.
- **App icon** for the exe and dialogs, generated by `tools/make_icon.py`.
- **Editing:** Cut, Copy, Paste, Select All, Save As
  (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>), Ctrl+mouse-wheel zoom, a
  word-wrap toggle, and <kbd>Alt</kbd>+<kbd>F</kbd>/<kbd>E</kbd>/<kbd>V</kbd>
  menu access.
- **High-DPI awareness** for crisp text.
- **Project tooling:** tests, ruff and mypy configuration, CI workflow, and
  documentation.

### Changed

- **Integrated title bar.** The menus now sit inside the custom title bar,
  replacing the detached native menu bar.
- **Layout:** the scrollbar and status bar no longer get pushed out of place.
- **Opacity controls** moved to the status bar, so they're no longer mistaken
  for minimise and maximise buttons.
- **Atomic saves:** a failed save can no longer truncate the file.
- **Unsaved changes:** the app prompts before discarding unsaved changes to a
  named file.

### Fixed

- **Ctrl+O** inserted a blank line before opening the dialog.
- **Double-clicking a word** in the editor moved the window.
- **The "Always on top" menu item** didn't stay in sync with the actual setting.
- **Global hotkey thread:** it called into Tk from a background thread, and it
  never unregistered the hotkey on exit.
- **The main window** was briefly capturable at startup, before protection was
  applied.
